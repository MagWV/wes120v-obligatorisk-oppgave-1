WES120V – Obligatorisk oppgave

Prosjektet er laget i forbindelse med en obligatorisk oppgave i WES120V.

Formålet med oppgaven er å bli bedre kjent med og vant til Vite, Git og GitHub som utviklingsverktøy. Prosjektet går ut på å opprette et minimalt Vite-prosjekt med en enkel HTML-side.

Forutsetninger
Prosjektet kan kun kjøres når Node.js og pnpm er installert på maskinen.

Installasjon
Åpne prosjektmappen i terminalen
Skriv: pnpm install
Forklaring: Kommandoen installerer avhengighetene som er nødvendige for prosjektet

Oppstart
Utviklingsserveren startes ved hjelp av:
pnpm dev

Da skal det komme opp en lokal adresse i terminalen. Du kan da kopiere adressen til nettleseren din for å se nettsiden.
